# 网页扩展屏指南

`idis` 的核心能力是通过浏览器将任意局域网设备变成主机的高清、低延迟扩展屏，观看端无需安装任何 App。

---

## 1. 管理端与观看端端口隔离

为避免将管理权限暴露在局域网中，`idis` 将管理端与观看端拆分为两个完全隔离的 HTTP 监听端口：

| 端口角色 | 默认监听地址 | 生命周期 | 允许路由 |
|---|---|---|---|
| **管理端（Admin）** | `127.0.0.1:8787`（可用 `--web-bind` 修改） | 启用 `--web` 时常驻 | `/`、`/admin`、`/api/admin/*`、`/api/auth/status` |
| **网页扩展屏（Viewer）** | `0.0.0.0:<随机端口>` | 仅在开启观看且配置口令时动态打开；关闭或空闲超时后立即关闭 | `/`（重定向至 `/view`）、`/view`、`/api/view/*`、`/ws/stream`、`/api/auth/status` |

关键安全保障：
- 管理端端口对 `/view`、`/api/view/*`、`/ws/stream` 直接返回 `404`。
- 观看端随机端口对 `/admin`、`/api/admin/*` 直接返回 `404`，且在任何情况下（包括本机回环）都不会授予管理员权限。
- 你**无需**将管理端改为 `--web-bind 0.0.0.0:8787`，只需保持管理端在 `127.0.0.1:8787`，开启观看后局域网设备即可直接通过随机观看端口扫码访问。

---

## 2. 空闲自动关闭机制

在管理端「接入端口与连接二维码」面板顶部，或通过 `--port-idle-close-secs`（默认 `300` 秒，`0` 表示不自动关闭）可以设置端口空闲自动关闭时间：

- 当网页扩展屏端口开启且**当前无在线观众、无待审批请求**时，开始空闲倒计时（管理界面实时显示剩余时间）。
- 一旦有观众连入，倒计时立即停止；当最后一位观众断开后重新计时。
- 超过设定时间后，系统自动关闭 `0.0.0.0` 随机观看端口，并**保留你的观看口令**，下次在管理后台点击「一键允许观看」即可重新分配随机端口并恢复服务。

## 3. 屏幕来源模式

在管理端「网页扩展屏」卡片或 CLI 参数 `--web-screen-mode` 中可随时热切换三种画面来源：

1. **独立扩展屏（`independent`，macOS Extend 模式专属）**
   - 自动创建一块独立的虚拟显示器供网页观众观看，与主机主屏幕及已连接的传统设备屏幕互不干扰。
   - 最后一个网页观众断开后自动释放该虚拟屏。
2. **电脑主屏幕（`main`）**
   - 直接采集主机主屏幕，不占用扩展屏配额，适用于演示、会议共享或 Linux / Windows 环境。
3. **跟随模式（`follow_ipad`）**
   - 当有传统扩展屏设备在线时共享其画面；无其他设备连接时，在 macOS Extend 模式下自动回退为独立扩展屏。

## 4. 浏览器播放与画质控制

- **流媒体封装**：后端将硬件 H.264 流实时封装为标准 fMP4（Fragmented MP4），通过 WebSocket 推送至浏览器的 `MediaSource`（iOS 17+ 自动适配 `ManagedMediaSource`）。
- **低延迟与后台省电**：
  - 支持在管理端独立配置网页端的分辨率、帧率（FPS）、码率（Mbps）、HiDPI 倍率与长边像素上限。
  - 当所有观看端浏览器标签页切换到后台或最小化时，主机自动暂停对应采集与编码以节省电量与 CPU。
- **快捷操作**：在 `/view` 页面双击画面或按 `F` 键进入/退出全屏。

---

## 5. 局域网 WebRTC P2P 中继

当有 **2 位及以上**网页观众同时观看时，`idis` 会自动通过 WebSocket 信令协商浏览器间的局域网 WebRTC DataChannel 中继树：

- 主机仅需发送一份流给根节点观众，由根节点在局域网内零服务器转发给下游观众，显著降低主机上传带宽压力。
- 仅在局域网直连协商（不依赖外部 STUN/TURN 服务器）；若某节点网络不通或离开，下游观众会自动无缝切回 WebSocket 直连，不中断播放。
- 如观看者之间互不信任，可在管理后台关闭「局域网 P2P 加速」。

---

## 6. 访问控制与审批

- **观看口令**：可通过 `--web-view-token` 或在管理端生成随机口令；重新生成或关闭口令会立即断开所有在线观众并使旧会话失效。
- **设备审批（可选）**：启用「网页观看需审批」（`--web-require-approval`）后，首次接入的浏览器在验证口令后需经管理员在网页后台或终端确认（支持「仅本次允许」「允许并信任」「拒绝」），并可在管理端随时撤销信任并立即踢出。
