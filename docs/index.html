01使用流程

四种连接方式按需选用，默认关门、用完即锁

平时管理页面仅限本机访问，不对外开放任何网络入口。使用浏览器或 Wi-Fi 投屏时，按需临时开启局域网观看入口，无人观看满 5 分钟自动关闭；使用 USB 数据线或纯本机虚拟屏时，全程零网络入口、免扫码直连。

一秒理解：就像一间只对熟人开放的临时放映室——无线观看时按开关才发入场券，散场 5 分钟自动锁门；插上数据线则像自家的有线通道，一插即通、拔线即停。

03技术原理

把画面实时切成浏览器直播小包裹，靠“完整底图”杜绝花屏

屏幕画面从显卡高速采集后，立刻压缩成浏览器直接可播的视频小段。系统每隔一小段时间发送一张完整底图，中间只传画面变化了哪些局部的轻量信息；一旦中途丢包，系统宁可跳过残缺变化等待下一张完整底图，绝不拼出绿屏或花屏。

一秒理解：就像连环画快递——定期寄一张完整底图，平时只寄写着“人物右移两步”的透明贴纸。贴纸丢了一张绝不硬贴，等下一张完整底图到了立刻恢复清晰。

04技术架构

安全、省电与稳定性，靠清晰的层次隔离兜底

整个系统按职责拆分为五层：对外的观看入口与本机控制室在入口层面彻底隔离，内部各模块按固定顺序协作防卡死，无人使用时彻底静音休眠，绝不拖累笔记本续航。

一秒理解：就像前台接待室与后台总控室分栋办公的现代化工厂——前门只能领观看画面，绝对进不了总控室；没人看时总闸自动断开，整栋楼彻底静音省电。

05弱网适配

Wi-Fi 变拥挤时只降画质细节不改分辨率，多人同看自动局域网接力

普通投屏遇到弱网往往直接降分辨率，导致副屏黑屏重建、窗口全部挤回主屏。idis 采用五档智能调速方案，全程保持原始分辨率不变，搭配实时防积压控流与多人局域网接力，兼顾跟手响应、画面稳定与多观众省流量。

一秒理解：高峰期堵车时，智能交警先让货车少装点细节、再少发几辆车，绝不把公路敲掉变窄重修；多人同看时，第一排观众把画面就近接力传给后排，主机轻松省下高达九成网络上传流量。
