# 传统扩展屏客户端兼容（可选）

除核心的**网页扩展屏**外，`idis` 还附带对传统 USB 与局域网 Wi-Fi 扩展屏客户端的兼容支持（默认仅允许 USB，Wi-Fi 监听端口默认关闭）。

---

## 1. USB 数据线连接

- 默认开启（可通过 `--no-usb` 禁用），通过本地 `usbmuxd` 通道自动发现已插线的设备，无需开放任何局域网监听端口。
- 物理直连设备默认免手动审批；如需严格二次确认，可传入 `--require-usb-confirm`。
- Windows 端使用 USB 通道需系统已安装 Apple Mobile Device Support（iTunes / Apple Devices）。

---

## 2. 局域网 Wi-Fi 接入端口（动态开关 + 空闲自动关闭）

为了减少不必要的端口暴露，Wi-Fi 监听端口默认关闭，支持两种方式按需开启：

1. **在 Web 管理端随时开关（推荐）**：
   - 在「接入端口与连接二维码」右侧的 **iPad Wi-Fi 接入端口** 卡片中点击**「开启 Wi-Fi 端口」**，立即开始监听并生成连接地址与二维码。
   - 点击**「关闭端口」**会立即断开 Wi-Fi 会话并释放监听端口与 Bonjour 广播（不影响正在使用的 USB 连接）。
   - 开启状态下若无活跃 Wi-Fi 设备连接超过 `port_idle_close_secs`（默认 `300` 秒），端口也会自动关闭。
2. **通过命令行启动**：
   ```bash
   idis --wifi --web
   ```
   可选参数：`--bind-addr`（绑定地址或网卡）、`--telemetry-port`（控制端口）、`--data-port`（数据端口）、`--no-bonjour`（关闭 mDNS 广播，仅手动填写 `IP:端口`）。

---

## 3. 可选交互与安全选项

- **远程触控与键盘输入**：默认关闭（仅观看），需显式传入 `--allow-input` 或在管理端开启。
- **客户端侧光标**：开启 `--client-cursor` 后将鼠标光标通过独立遥测通道同步渲染，降低视频帧冗余更新。
- **失焦自动降帧**：开启 `--half-fps-unfocused` 后，当光标不在扩展屏上时自动将帧率减半以节省电量。
- **局域网设备审批与白名单**：首次通过 Wi-Fi 接入的设备需在管理后台或终端一键审批（仅本次允许 / 加入信任列表 / 拒绝）；也可配合 `--allow-ip` 限制来源网段。

> [!WARNING]
> 传统 Wi-Fi 兼容通道采用明文局域网 TCP 传输，建议仅在受信任的家庭/办公局域网或 VPN 中使用，避免在公共 Wi-Fi 下同时开启 `--wifi` 与 `--allow-input`。
